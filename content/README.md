# Content layer

This directory separates technical knowledge from Streamlit rendering code.

## Rule

Every technical statement should carry one of four evidence states:

- `tutorial_direct`
- `tutorial_derived`
- `engineering_model`
- `frontier`

Unverified conference notes should stay in `pending_verification` until checked against the tutorial page or a primary publication.
